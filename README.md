# GitHub Pages Repo Scaffold

This directory mirrors the structure of an organization site repository such as `<owner>.github.io`.

To match the MovieDreamer setup:

1. Create or use the repository `<owner>.github.io`
2. Copy the local `MMControl/` directory from here into that repository
3. Commit and push
4. The project page will be available at `https://<owner>.github.io/MMControl/`

If you already have an organization homepage repo, only the `MMControl/` subdirectory is needed.
